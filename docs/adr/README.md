# Architecture Decision Records

ADRs document significant architectural decisions using numbered Markdown files
with context, decision, alternatives, and consequences. They record decisions,
not proof that the planned implementation already exists.

| ADR | Status |
| --- | --- |
| [0001: Shared hotel application layer for Windows Forms and MCP](0001-shared-hotel-application-layer-and-mcp.md) | Accepted |

Drafts are Proposed until reviewed and approved by the repository owner.
Accepted records remain part of the history. Use a new numbered ADR to
supersede a materially changed decision and cross-link the records.
